# Matematică pe pași

Pregătire în română pentru legi de compoziție, grupuri și integrale: 25 de lecții, 30 de probleme rezolvate și 49 de fotografii originale.

Site static, fără instalare sau dependențe externe. Deschide `index.html` sau activează GitHub Pages pentru rădăcina ramurii `main`.

Răspunsurile acceptă fracții și zecimale. Progresul și cronometrul se păstrează în browser când stocarea locală este disponibilă.
